# Release v3.1.0

## Resumo executivo

Este release consolida em `master` todo o trabalho da **Fase 2** (observabilidade, segurança em nível de linha, busca híbrida, timeline materializada) e o **Data-Centric AI cleanup** realizado na camada de dados e modelagem, além de corrigir a referência dos workflows CI para a branch `master`.

## Principais mudanças

### Fase 2 — Observabilidade

- `src/observability/metrics.py` com métricas padronizadas de ML.
- `LatencyTracker` para instrumentação de latência por fase.
- Endpoints FastAPI `/metrics` e `/health`.
- Stack Docker Compose com Prometheus + Grafana e dashboard JSON.

### Fase 2 — Knowledge / Hybrid Search

- `src/knowledge/hybrid_search.py` combinando BM25 (FTS5), busca vetorial e RRF.
- Migration FTS5 (`001_fts5_hybrid.sql`).
- Integração do hybrid search no retriever, CLI e MCP server.
- Golden dataset em `data/eval/golden_dataset.json` e `scripts/eval_hybrid.py`.

### Fase 2 — Segurança e Auditoria

- Row-Level Security por `owner_id` (`src/security/rls.py`).
- Integração de RLS em `src/knowledge/structured_query.py`.
- Audit log completo com `user_id`, SQL final e parâmetros.
- Corpus adversarial (`tests/stress/adversarial_corpus.jsonl`) e fuzz testing.

### Fase 2 — Tracking / Timeline

- Tabela materializada de timeline (`002_materialized_timeline.sql`).
- `TimelineRefresher` async e refresh hook pós-run.
- Teste de stress com 1M runs.

### Data-Centric AI cleanup

- Clipping de amplitude em ±5mV para remover artefatos de saturação.
- Z-score global calculado apenas no treino e aplicado consistentemente em val/test.
- `StandardScaler` ajustado apenas no treino para features do MLP, com scaler persistido.
- Flag `--force-rebuild` para invalidação de cache `.dat`/`.npz`.
- Refatorações para reduzir duplicação e resolver issues do SonarCloud (S107, S2083, S3649, S8707, S117).

### CI/CD

- Correção dos workflows GitHub Actions: referências à branch inexistente `main` foram alteradas para `master`.
- Workflow `stress-gate.yml` para testes de carga.

## Breaking changes

Nenhuma breaking change documentada. APIs de alto nível (`train_group_kfold`, scripts de treinamento, CLI C11) mantêm compatibilidade retroativa.

## Quality gates

- `make lint` ✅
- SonarCloud Quality Gate ✅ (0 new issues, 0 security hotspots, < 3% duplication)
- CI checks disparam em PRs para `master` ✅
